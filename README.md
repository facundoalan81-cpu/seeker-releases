# Seeker — descargas

Binarios de **Seeker**, el buscador universal de tracks para DJs.
Este repo sólo aloja el instalador; el código fuente no vive acá.

- **Última versión:** [Seeker 0.2.0 para macOS (Apple Silicon)](https://github.com/facundoalan81-cpu/seeker-releases/releases/latest/download/Seeker-0.2.0.dmg)
- **Web:** https://seeker-cloud.vercel.app

## Instalación

1. Bajá el `.dmg` y arrastrá **Seeker** a Aplicaciones.
2. La primera vez abrilo con **click derecho → Abrir** (la app no está firmada por Apple).

Seeker usa tus propias cuentas en tu propia máquina. No aloja ni distribuye música.
